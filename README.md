# 🏠 AI House Price Prediction System

Machine Learning web application that predicts house prices using Gradient Boosting Regression.

## Features

- ML pipeline with preprocessing
- Gradient Boosting model
- Streamlit UI
- Explainable feature importance
- Production-ready deployment

## Tech Stack

Python
Scikit-learn
Pandas
Streamlit
Plotly
UV

## Run Locally

```bash
uv sync

uv run streamlit run app.py
